# Dhaka Tesla Pool

A ride-pooling application for Dhaka where passengers can share available seats in a Tesla, split fares fairly, and follow the ride lifecycle from request to completion.

## Project Status

Development in progress.

## Core Goals

- Support passenger and driver workflows.
- Match compatible ride requests into shared pools.
- Enforce vehicle seat capacity safely.
- Calculate an individual fare for each passenger.
- Maintain valid ride lifecycle transitions.
- Preserve data consistency under concurrent booking attempts.

## Story

Jashim drives **Bullet**, a three-seat battery-powered Tesla in Dhaka. Nusrat, Rafiq, and Shirin request overlapping rides, creating the core pooling, capacity, fare, and concurrency scenarios used throughout the project.
